# Never-miss v2, Plan 1: Foundations — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the foundation layer of the v2 scraper: the package, a hash-locked toolchain
and the four gates; the data model; the monitored window; the civil-date grammar; the place
and institution registries; and the HTTP fetcher with its trust store. Every part is
unit-tested and mutation-checked. v1 (`scraper.py`, the workflow, the extension) keeps running
unchanged.

**Architecture:** A new package `elections_calendar/`, laid out as spec §4 describes.
This plan builds layers 6 and 7 (`fetch | dates | places | offices | window`, then
`model | text`). import-linter enforces the layer order, and every higher layer stays optional
until the plan that creates it. Reference data (`data/places.yaml`, `data/institutions.yaml`)
is generated by scripts from committed inputs and checked by tests for being up to date.

**Tech Stack:** Python 3.14.1; runtime `requests` 2.34.2 (urllib3 2.8.0), `certifi` 2026.7.22,
`PyYAML` 6.0.3, plus `beautifulsoup4` 4.15.0, `lxml` 6.1.3 and `jsonschema` 4.26.0 for later
plans; development `pytest` 9.1.1, `mypy` 2.4.0 (strict), `ruff` 0.17.1, `import-linter` 2.15,
`pip-tools` 7.6.2, `pycountry` 26.2.16 (build script only), `cryptography` 50.0.2 (test
certificates only), `hypothesis`, `playwright`, `pytest-playwright` (later plans).

**Spec:** `docs/superpowers/specs/2026-10-16-never-miss-v2-design.md` at commit `b16b54f`
(approved). Read §4, §5.1–§5.2, §6, §8, §13.4, §14 and §16 before you start. Where this plan and
the spec differ, the plan is right *only* for the items listed under "Spec corrections" below.

## Review Focus

The five inputs most likely to hurt a user that the spec implies but does not spell out. Each
is pinned by the tests named here, in the task that owns the code:

1. **Unicode look-alikes in real page text** (non-breaking spaces, en/em/figure dashes, the
   minus sign, non-breaking hyphens, accented names): parsed exactly like their ASCII forms,
   never as leftover. Pinned by `test_nbsp_and_em_dash_are_normalised` and `test_day_ranges`
   (Task 4), `test_norm_name` (Task 2), `test_real_source_spellings_resolve` and
   `test_empty_country_text_resolves_to_nothing` (Task 5).
2. **Impossible dates and reversed ranges** (`31 Sep 2026`, `29 Feb 2027`, `2026-02-30`,
   `20 Sep – 18 Sep 2026`): never a date; the text stays as leftover so the unit becomes
   partial, not dropped. Pinned by `test_unparseable_text_is_leftover_never_dropped` (Task 4)
   and `test_invalid_spans_are_rejected` (Task 2).
3. **Ranges that cross a year with no start year** (`30 December – 2 January` on the 2026
   page, `24 December – 6 February 2027`): the start falls in the earlier year. Pinned by
   `test_day_ranges` (Task 4).
4. **A naive or non-UTC "now"**: a naive time is refused; an aware time is converted to the
   UTC civil date, so 23:30 on 31 Oct in New York is a November window. Pinned by
   `test_naive_now_is_rejected` and `test_now_is_converted_to_the_utc_civil_date` (Task 3),
   `test_claim_rejects_naive_fetched_at` and `test_claim_serialises_non_utc_provenance_as_utc`
   (Task 2).
5. **Misbehaving servers** (bytes dripped slowly, an endless body, a redirect to `http`, a
   challenge page with HTTP 200, an HTML error page from the MediaWiki API, an unknown
   charset): each ends in bounded time with a named outcome and a redacted error, never an
   exception or a hang. Pinned by `test_a_dripping_body_cannot_outlast_the_attempt_limit`,
   `test_an_oversized_body_is_refused`, `test_a_redirect_to_http_is_refused`,
   `test_challenge_pages_are_detected`, `test_mediawiki_non_json_is_an_api_error` and
   `test_text_falls_back_to_utf8_for_an_unknown_charset` (Task 7).

```python
"""Mutation checks: every mutation in a table must make its test fail.

    .venv/Scripts/python.exe .scratch/mutate.py .scratch/mutations/task-N.json

Each entry is {"test": "<pytest node id>", "file": "<path>", "old": "<exact
text>", "new": "<replacement>"}; "old" must occur exactly once in the file.
Stage the task's files first (git add): each mutation is undone with
`git checkout -- <file>`, which restores the staged copy, and then checked
with `git diff --exit-code -- <file>`.
"""

import json
import os
import subprocess
import sys
from pathlib import Path


def git(*args: str) -> int:
    return subprocess.run(["git", *args], capture_output=True).returncode


def check(entry: dict[str, str], env: dict[str, str]) -> str:
    path = Path(entry["file"])
    if git("ls-files", "--error-unmatch", "--", str(path)) != 0:
        return f"NOT STAGED {path}: git add it before mutating"
    if git("diff", "--quiet", "--", str(path)) != 0:
        return f"UNSTAGED   {path} has changes the index lacks: git add it first"
    text = path.read_bytes().decode("utf-8")
    if text.count(entry["old"]) != 1:
        return f"BAD TABLE  {entry['test']}: the text to replace is not unique in {path}"
    path.write_bytes(text.replace(entry["old"], entry["new"], 1).encode("utf-8"))
    try:
        if path.suffix == ".py":
            try:
                compile(path.read_bytes(), str(path), "exec")
            except SyntaxError:
                return f"BAD TABLE  {entry['test']}: the mutation is not valid Python"
        run = subprocess.run(
            [sys.executable, "-m", "pytest", "-q", "-p", "no:cacheprovider", entry["test"]],
            env=env,
            capture_output=True,
            text=True,
        )
    finally:
        if git("checkout", "--", str(path)) != 0 or git("diff", "--exit-code", "--", str(path)):
            print(f"RESTORE FAILED for {path}: stop and restore it by hand from the index")
            sys.exit(3)
    lines = run.stdout.strip().splitlines()
    summary = lines[-1] if lines else run.stderr.strip()[-200:]
    verdict = "KILLED  " if run.returncode != 0 else "SURVIVED"
    return f"{verdict} {entry['test']}  ({summary})"


def main(table: Path) -> int:
    env = {**os.environ, "PYTHONDONTWRITEBYTECODE": "1"}
    entries = json.loads(table.read_text(encoding="utf-8"))
    results = [check(entry, env) for entry in entries]
    for line in results:
        print(line)
    killed = sum(line.startswith("KILLED") for line in results)
    print(f"{killed}/{len(entries)} mutations killed")
    return 0 if killed == len(entries) else 1


if __name__ == "__main__":
    sys.exit(main(Path(sys.argv[1])))
```

```python
"""Text normalisation shared by every layer (stdlib only)."""

import re
import unicodedata

_WS = re.compile(r"\s+")
_APOSTROPHES = str.maketrans({"’": "'", "‘": "'", "`": "'", "´": "'", "ʼ": "'"})
_NON_WORD = re.compile(r"[^a-z0-9']+")


def collapse_ws(text: str) -> str:
    """Collapse every run of whitespace (including NBSP) to one space and strip."""
    return _WS.sub(" ", text).strip()


def fold(text: str) -> str:
    """Case-fold, unify apostrophes and drop diacritics: "São Tomé" -> "sao tome"."""
    decomposed = unicodedata.normalize("NFKD", text.translate(_APOSTROPHES))
    return "".join(c for c in decomposed if not unicodedata.combining(c)).casefold()


def norm_name(text: str) -> str:
    """Matching key for names: folded, punctuation to spaces, no leading/trailing "the".

    "Gambia (The)", "Gambia, The" and "The Gambia" all give "gambia".
    """
    key = _NON_WORD.sub(" ", fold(text).replace("&", " and ")).strip(" '")
    key = collapse_ws(key)
    if key.startswith("the "):
        key = key[4:]
    if key.endswith(" the"):
        key = key[:-4]
    return key


def slug(text: str) -> str:
    """Identifier fragment: norm_name with apostrophes dropped and spaces as hyphens."""
    return norm_name(text).replace("'", "").replace(" ", "-")
```

```python
def month_end(year: int, month: int) -> date:
    """Last civil day of the month."""
    return date(year, month, calendar.monthrange(year, month)[1])


@dataclass(frozen=True, slots=True)
class DateSpan:
    """A civil-date interval (spec §5.2).

    Day and month precision always have ``start`` and ``end`` (inclusive);
    month precision runs from the 1st of the start month to the last day of
    the end month. Year precision ("2026") has neither and is never bucketed.
    """

    start: date | None
    end: date | None
    precision: Precision
    year: int

    def __post_init__(self) -> None:
        if self.precision == "year":
            if self.start is not None or self.end is not None:
                raise ValueError("year precision has no start or end")
            return
        if self.start is None or self.end is None:
            raise ValueError(f"{self.precision} precision needs start and end")
        if self.end < self.start:
            raise ValueError(f"end {self.end} is before start {self.start}")
        if self.year != self.start.year:
            raise ValueError(f"year {self.year} differs from start {self.start}")
        if self.precision == "month" and (
            self.start.day != 1 or self.end != month_end(self.end.year, self.end.month)
        ):
            raise ValueError("month precision must cover whole months")

    @classmethod
    def day(cls, d: date) -> DateSpan:
        return cls(d, d, "day", d.year)

    @classmethod
    def days(cls, start: date, end: date) -> DateSpan:
        return cls(start, end, "day", start.year)

    @classmethod
    def month(cls, year: int, month: int) -> DateSpan:
        return cls(date(year, month, 1), month_end(year, month), "month", year)

    @classmethod
    def months(cls, year1: int, month1: int, year2: int, month2: int) -> DateSpan:
        return cls(date(year1, month1, 1), month_end(year2, month2), "month", year1)

    @classmethod
    def of_year(cls, year: int) -> DateSpan:
        return cls(None, None, "year", year)

    def to_dict(self) -> dict[str, Any]:
        return {
            "date": self.start.isoformat() if self.start else None,
            "end_date": self.end.isoformat() if self.end else None,
            "date_precision": self.precision,
            "year": self.year,
        }

    @classmethod
    def from_dict(cls, data: dict[str, Any]) -> DateSpan:
        start = date.fromisoformat(data["date"]) if data["date"] else None
        end = date.fromisoformat(data["end_date"]) if data["end_date"] else None
        return cls(start, end, data["date_precision"], int(data["year"]))


@dataclass(frozen=True, slots=True)
class InputUnit:
    """One discovered input unit and its single ledger outcome (spec §7, §9.1).

    ``unit_id`` is ``<source>:<page key>/<position>``: where the unit was
    observed, never a publisher event ID.
    """

    unit_id: str
    source: str
    text: str
    outcome: Outcome
    reason: str | None
    relevance: Relevance
    leftover: str = ""
```

```python
"""The monitored window and month buckets (spec §5.1).

Window = [M-1, M, M+1, M+2, M+3], where M is the month of the generation's
UTC civil date T.
"""

from dataclasses import dataclass
from datetime import UTC, date, datetime

from elections_calendar.model import DateSpan, month_end

MONTHS_BACK = 1
MONTHS_AHEAD = 3


def add_months(year: int, month: int, delta: int) -> tuple[int, int]:
    """(year, month) shifted by ``delta`` months."""
    index = year * 12 + (month - 1) + delta
    return index // 12, index % 12 + 1


def month_key(year: int, month: int) -> str:
    return f"{year:04d}-{month:02d}"


@dataclass(frozen=True, slots=True)
class Window:
    today: date
    months: tuple[tuple[int, int], ...]

    @property
    def start(self) -> date:
        year, month = self.months[0]
        return date(year, month, 1)

    @property
    def end(self) -> date:
        year, month = self.months[-1]
        return month_end(year, month)

    @property
    def years(self) -> tuple[int, ...]:
        """Every calendar year the window touches (the requested years)."""
        return tuple(sorted({year for year, _ in self.months}))

    @property
    def month_keys(self) -> tuple[str, ...]:
        return tuple(month_key(year, month) for year, month in self.months)

    @property
    def current_month(self) -> str:
        return month_key(self.today.year, self.today.month)

    def overlaps(self, span: DateSpan) -> bool:
        """True when a dated span overlaps the window; year precision never does."""
        if span.start is None or span.end is None:
            return False
        return span.start <= self.end and span.end >= self.start

    def bucket(self, span: DateSpan) -> str | None:
        """The one month bucket for a dated span, or None (undated / outside).

        Spec §5.1: the start month if it is in the window, otherwise the first
        window month the interval overlaps. Both are the first window month
        the interval overlaps, which is what this returns.
        """
        if span.start is None or span.end is None:
            return None
        for year, month in self.months:
            if date(year, month, 1) <= span.end and month_end(year, month) >= span.start:
                return month_key(year, month)
        return None


def window_for(now: datetime) -> Window:
    """Window for the generation time ``now`` (timezone-aware; converted to UTC)."""
    if now.utcoffset() is None:
        raise ValueError("now must be timezone-aware")
    today = now.astimezone(UTC).date()
    months = tuple(
        add_months(today.year, today.month, delta)
        for delta in range(-MONTHS_BACK, MONTHS_AHEAD + 1)
    )
    return Window(today=today, months=months)
```

```python
"""Civil-date grammar for source text (spec §6.1).

Dates are year/month/day components (``datetime.date``); nothing here goes
through a timestamp or a time zone. ``parse_date_text`` extracts status words
first, then parses what is left with one of the full-match forms below. Text
it cannot account for is returned as ``leftover``, never silently dropped.
"""

import re
from dataclasses import dataclass
from datetime import date

from elections_calendar.model import DateSpan, DateStatus, Relevance, StatusClaim, month_end
from elections_calendar.text import collapse_ws

MONTH_NUMBERS: dict[str, int] = {
    "jan": 1, "january": 1, "feb": 2, "february": 2, "mar": 3, "march": 3,
    "apr": 4, "april": 4, "may": 5, "jun": 6, "june": 6, "jul": 7, "july": 7,
    "aug": 8, "august": 8, "sep": 9, "sept": 9, "september": 9, "oct": 10,
    "october": 10, "nov": 11, "november": 11, "dec": 12, "december": 12,
}  # fmt: skip

_MONTH = (
    r"(?:jan(?:uary)?|feb(?:ruary)?|mar(?:ch)?|apr(?:il)?|may|june?|july?|aug(?:ust)?"
    r"|sep(?:t(?:ember)?)?|oct(?:ober)?|nov(?:ember)?|dec(?:ember)?)\b\.?"
)
_DAY = r"\d{1,2}(?:st|nd|rd|th)?"
_YEAR = r"\d{4}"
_DASH = r"\s*(?:-|\bto\b|\buntil\b|\bthrough\b)\s*"
_OPT_YEAR = r"(?:,?\s+(?P<{name}>\d{{4}}))?"


def _full(pattern: str) -> re.Pattern[str]:
    return re.compile(rf"^{pattern}$", re.IGNORECASE)


def _y(name: str) -> str:
    return _OPT_YEAR.format(name=name)


_ISO = _full(r"(?P<y>\d{4})-(?P<m>\d{1,2})-(?P<d>\d{1,2})")
_DMY_DMY = _full(
    rf"(?P<d1>{_DAY})\s+(?P<m1>{_MONTH}){_y('y1')}{_DASH}(?P<d2>{_DAY})\s+(?P<m2>{_MONTH}){_y('y2')}"
)
_DD_M = _full(rf"(?P<d1>{_DAY}){_DASH}(?P<d2>{_DAY})\s+(?P<m2>{_MONTH}){_y('y2')}")
_MD_MD = _full(

)
_M_DD = _full(rf"(?P<m1>{_MONTH})\s+(?P<d1>{_DAY}){_DASH}(?P<d2>{_DAY}){_y('y2')}")
_DMY = _full(rf"(?P<d>{_DAY})\s+(?P<m>{_MONTH}){_y('y')}")
_MDY = _full(rf"(?P<m>{_MONTH})\s+(?P<d>{_DAY}){_y('y')}")
_M_M = _full(rf"(?P<m1>{_MONTH}){_y('y1')}{_DASH}(?P<m2>{_MONTH}){_y('y2')}")
_MY = _full(rf"(?P<m>{_MONTH}){_y('y')}")
_YEAR_ONLY = _full(r"(?P<y>\d{4})")
_LIST_ITEM = rf"{_DAY}(?:\s+{_MONTH})?"

_LIST_SPLIT = re.compile(r"\s*,\s*(?:and\s+)?|\s+and\s+", re.IGNORECASE)

_DASHES = str.maketrans(dict.fromkeys("\u2013\u2014\u2012\u2212\u2010\u2011", "-"))
_YEAR_THEN_LETTER = re.compile(r"(\d{4})(?=[A-Za-z])")
_POSTPONED = re.compile(

    (re.compile(r"\(t\)", re.IGNORECASE), "(t)"),
    (re.compile(r"\bdate not confirmed\b", re.IGNORECASE), "date not confirmed"),

    (re.compile(r"\bupcoming\b", re.IGNORECASE), "upcoming"),
    (re.compile(r"\bpast\b", re.IGNORECASE), "past"),
    (re.compile(r"\bcancel+ed\b", re.IGNORECASE), "cancelled"),
    (re.compile(r"\bdisputed\b", re.IGNORECASE), "disputed"),
    (re.compile(r"\bheld\b", re.IGNORECASE), "held"),

    (re.compile(r"\*+"), "*"),
)
_TENTATIVE_WORDS = frozenset({"(t)", "date not confirmed", "tbd", "tentative", "expected"})
_STATUS_ORDER: tuple[StatusClaim, ...] = ("cancelled", "postponed", "disputed", "held")
_EDGE_PUNCT = " ,;:-"


@dataclass(frozen=True, slots=True)
class DateParse:
    """Result of parsing one date text.

    ``spans`` is empty when the text holds no date of its own (e.g. only
    "Postponed from April 2026"). ``leftover`` is the text that could not be
    parsed; it is "" when everything was accounted for.
    """

    spans: tuple[DateSpan, ...]
    date_status: DateStatus
    status_claim: StatusClaim | None
    status_words: tuple[str, ...]
    previous_text: str | None
    previous_spans: tuple[DateSpan, ...]
    leftover: str
    phased: bool

    @property
    def ok(self) -> bool:
        return not self.leftover


def parse_date_text(text: str, *, default_year: int | None = None) -> DateParse:
    """Parse a source's date text; ``default_year`` fills in a missing year."""
    clean = _YEAR_THEN_LETTER.sub(r"\1 ", collapse_ws(text.translate(_DASHES)))
    words: list[str] = []
    previous_text: str | None = None
    previous_spans: tuple[DateSpan, ...] = ()
    postponed = _POSTPONED.search(clean)
    if postponed:
        words.append("postponed")
        previous_text = (postponed.group("prev") or "").strip(_EDGE_PUNCT) or None
        if previous_text:
            previous_spans, prev_left = _parse_core(previous_text, default_year)
            if prev_left:
                previous_spans = ()
        clean = f"{clean[: postponed.start()]} {postponed.group('new') or ''}"
    for pattern, word in _MARKERS:
        if pattern.search(clean):
            words.append(word)
            clean = pattern.sub(" ", clean)
    core = collapse_ws(clean).strip(_EDGE_PUNCT)
    spans, leftover = _parse_core(core, default_year) if core else ((), "")
    return DateParse(
        spans=spans,
        date_status=_date_status(words),
        status_claim=next((s for s in _STATUS_ORDER if s in words), None),
        status_words=tuple(words),
        previous_text=previous_text,
        previous_spans=previous_spans,
        leftover=leftover,
        phased="staggered" in words,
    )


def _date_status(words: list[str]) -> DateStatus:
    if any(w in _TENTATIVE_WORDS for w in words):
        return "tentative"
    if "(d)" in words:
        return "confirmed"
    return "unknown"


def _parse_core(core: str, default_year: int | None) -> tuple[tuple[DateSpan, ...], str]:
    """Spans for ``core`` (no status words left), or ((), core) when it doesn't parse."""
    try:
        spans = _match(core, default_year)
    except ValueError:
        spans = None
    return (spans, "") if spans else ((), core)


def _match(core: str, default_year: int | None) -> tuple[DateSpan, ...] | None:
    if m := _ISO.match(core):
        return (DateSpan.day(date(int(m["y"]), int(m["m"]), int(m["d"]))),)
    for pattern in (_DMY_DMY, _DD_M, _MD_MD, _M_DD):
        if m := pattern.match(core):
            return (_day_range(m.groupdict(), default_year),)
    for pattern in (_DMY, _MDY):
        if m := pattern.match(core):
            year = _year(m["y"], default_year)
            return (DateSpan.day(date(year, _month(m["m"]), _day(m["d"]))),)
    if m := _M_M.match(core):
        m1, m2 = _month(m["m1"]), _month(m["m2"])
        y1, y2 = _range_years(m["y1"], m["y2"], default_year, (m1, 1), (m2, 1))
        return (DateSpan.months(y1, m1, y2, m2),)
    if m := _MY.match(core):
        return (DateSpan.month(_year(m["y"], default_year), _month(m["m"])),)
    if m := _YEAR_ONLY.match(core):
        return (DateSpan.of_year(int(m["y"])),)
    if m := _LIST.match(core):
        return _day_list(m["items"], _year(m["y"], default_year))
    return None


def _day(token: str) -> int:
    digits = re.match(r"\d+", token)
    if digits is None:
        raise ValueError(f"no day in {token!r}")
    return int(digits.group())


def _month(token: str) -> int:
    return MONTH_NUMBERS[token.rstrip(".").casefold()]


def _year(token: str | None, default_year: int | None) -> int:
    if token:
        return int(token)
    if default_year is None:
        raise ValueError("no year in the text and no default year")
    return default_year


def _range_years(
    y1: str | None,
    y2: str | None,
    default_year: int | None,
    first: tuple[int, int],
    last: tuple[int, int],
) -> tuple[int, int]:
    """Years for a range whose ends may omit them.

    The end rolls into the next year when its month is earlier than the
    start's ("30 December - 2 January"); within one month an inverted range
    stays invalid. Only the end year given: the start takes it, or the year
    before. No year at all: the default is the start's.
    """
    rolls = last[0] < first[0]
    if y1 is not None and y2 is not None:
        return int(y1), int(y2)
    if y2 is not None:
        end = int(y2)
        return (end - 1 if rolls else end), end
    start = int(y1) if y1 is not None else _year(None, default_year)
    return start, (start + 1 if rolls else start)


def _day_range(groups: dict[str, str | None], default_year: int | None) -> DateSpan:
    first_month = groups.get("m1") or groups.get("m2")
    last_month = groups.get("m2") or groups.get("m1")
    if first_month is None or last_month is None:
        raise ValueError("day range without a month")
    m1, m2 = _month(first_month), _month(last_month)
    d1, d2 = _day(groups.get("d1") or ""), _day(groups.get("d2") or "")
    y1, y2 = _range_years(groups.get("y1"), groups.get("y2"), default_year, (m1, d1), (m2, d2))
    return DateSpan.days(date(y1, m1, d1), date(y2, m2, d2))


def _day_list(items: str, year: int) -> tuple[DateSpan, ...]:
    """'16 March, 18 June, and 16 October' -> one span per date; '4 and 18 Oct' shares a month."""
    tokens = [t for t in _LIST_SPLIT.split(items) if t]
    month: int | None = None
    days: list[date] = []
    for token in reversed(tokens):
        parts = token.split()
        if len(parts) == 2:
            month = _month(parts[1])
        if month is None:
            raise ValueError(f"no month for {token!r}")
        days.append(date(year, month, _day(parts[0])))
    return tuple(DateSpan.day(d) for d in sorted(days))


# --- helpers for adapters -------------------------------------------------


def month_of(span: DateSpan) -> DateSpan:
    """The month-precision span covering ``span`` (NDI 'TBD' rows, IPU month ends)."""
    if span.start is None or span.end is None:
        return span
    return DateSpan.months(span.start.year, span.start.month, span.end.year, span.end.month)


def make_range(first: DateSpan, last: DateSpan) -> DateSpan:
    """Day interval from ``first``'s start to ``last``'s end (ElectionGuide Start/End)."""
    if first.precision != "day" or last.precision != "day":
        raise ValueError("make_range needs two day-precision spans")
    if first.start is None or last.end is None:
        raise ValueError("make_range needs dated spans")
    return DateSpan.days(first.start, last.end)


def plausible(span: DateSpan, today: date, years: int = 5) -> bool:
    """Spec §9.2: the span's years lie within ±``years`` of T."""
    last = span.end.year if span.end else span.year
    return abs(span.year - today.year) <= years and abs(last - today.year) <= years

def relevance(text: str, window_start: date, *, default_year: int | None = None) -> Relevance:
    """Relevance of a unit's text to the window (spec §6.1).

    in_or_after_window: a date in the text ends on or after the window start,
    or a year that is not part of a date is >= the window start's year.
    before_window: every year mentioned (inside dates or bare) is before the
    window start's year, and there is no "postponed"/"to" marker.
    Otherwise unknown (including text with no date or year at all).
    """
    clean = collapse_ws(text.translate(_DASHES))
    date_ends: list[date] = []
    years: list[int] = []
    covered: list[tuple[int, int]] = []
    for m in _SCAN.finditer(clean):
        end = _scan_end(m, default_year)
        explicit = m["y1"] or m["y2"] or m["y3"] or (m["iso"] or "")[:4]
        if end is not None:
            date_ends.append(end)
            years.append(end.year)
            covered.append(m.span())
        elif explicit:
            years.append(int(explicit))
            covered.append(m.span())
    bare = [
        int(m.group())
        for m in _BARE_YEAR.finditer(clean)
        if not any(a <= m.start() < b for a, b in covered)
    ]
    years.extend(bare)
    if any(end >= window_start for end in date_ends) or any(y >= window_start.year for y in bare):
        return "in_or_after_window"
    if years and all(y < window_start.year for y in years) and not _CHANGE_MARKER.search(clean):
        return "before_window"
    return "unknown"


def _scan_end(m: re.Match[str], default_year: int | None) -> date | None:
    """Last civil day of a scanned date, or None when it isn't a valid date."""
    try:
        if m["iso"]:
            return date.fromisoformat(_zero_pad_iso(m["iso"]))
        if m["d1"]:
            year = int(m["y1"]) if m["y1"] else default_year
            if year is None:
                return None
            return date(year, _month(m["m1"]), _day(m["d1"]))
        if m["d2"]:
            return date(int(m["y2"]), _month(m["m2"]), _day(m["d2"]))
        return month_end(int(m["y3"]), _month(m["m3"]))
    except ValueError:
        return None


def _zero_pad_iso(text: str) -> str:
    y, mo, d = text.split("-")
    return f"{y}-{int(mo):02d}-{int(d):02d}"
```

```python
"""Count the country strings in every published elections.json in git history.

Writes data/feed_country_history.tsv, the frozen display-name evidence used
by scripts/build_places.py (spec §6.2). Read-only on the repository.

    .venv\\Scripts\\python.exe -m scripts.count_feed_countries ff30417
"""

import argparse
import collections
import json
import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
OUT = ROOT / "data" / "feed_country_history.tsv"


def git(*args: str) -> bytes:
    return subprocess.run(["git", *args], cwd=ROOT, check=True, capture_output=True).stdout


def count(ref: str) -> tuple[collections.Counter[str], int]:
    commits = git("log", "--format=%H", ref, "--", "elections.json").decode().split()
    counts: collections.Counter[str] = collections.Counter()
    for commit in commits:
        feed = json.loads(git("show", f"{commit}:elections.json").decode("utf-8"))
        for records in (feed.get("months") or {}).values():
            for record in records:
                counts[str(record.get("country", ""))] += 1
    return counts, len(commits)


def main(argv: list[str]) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("ref", help="last commit to include, e.g. ff30417")
    args = parser.parse_args(argv)
    counts, feeds = count(args.ref)
    lines = [
        f"# Country strings in the {feeds} elections.json versions up to {args.ref}.",
        "# Generated by scripts/count_feed_countries.py; do not edit.",
        "country\tcount",
        *(f"{name}\t{n}" for name, n in sorted(counts.items()) if name.strip()),
    ]
    OUT.parent.mkdir(exist_ok=True)
    OUT.write_text("\n".join(lines) + "\n", encoding="utf-8", newline="\n")
    print(f"{len(counts)} strings from {feeds} feeds -> {OUT.relative_to(ROOT)}")
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

Create `elections_calendar/places.py`:

```python
"""Place resolution (spec §6.2): raw source country text -> place.

``data/places.yaml`` is generated by ``scripts/build_places.py``. Names match
on ``text.norm_name`` (case, accents, punctuation, a leading/trailing "the").
A name that is not registered still gets a deterministic ``x:<slug>`` place
with ``registered=False``: two unregistered names match only when their
normalised names are identical, and the adapter marks the unit partial with
reason ``place_unregistered`` (spec §9.2).
"""

import re
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import yaml

from elections_calendar.text import collapse_ws, norm_name, slug

DEFAULT_PLACES = Path(__file__).resolve().parent.parent / "data" / "places.yaml"
_PART_OF = re.compile(r"^(?P<name>.+?)\s*\(part of (?P<parent>.+)\)$", re.IGNORECASE)


@dataclass(frozen=True, slots=True)
class Place:
    place_id: str
    display: str
    country_code: str | None
    parent: str | None
    registered: bool = True


class PlaceRegistry:
    def __init__(self, places: dict[str, Place], aliases: dict[str, str]) -> None:
        self._places = places
        self._aliases = aliases

    @classmethod
    def load(cls, path: Path = DEFAULT_PLACES) -> PlaceRegistry:
        raw: dict[str, dict[str, Any]] = yaml.safe_load(path.read_text(encoding="utf-8"))
        places: dict[str, Place] = {}
        aliases: dict[str, str] = {}
        for place_id, entry in raw.items():
            places[place_id] = Place(
                place_id, entry["display"], entry["country_code"], entry["parent"]
            )
            for alias in entry["aliases"]:
                owner = aliases.setdefault(norm_name(alias), place_id)
                if owner != place_id:
                    raise ValueError(f"alias {alias!r} names both {owner} and {place_id}")
        return cls(places, aliases)

    def get(self, place_id: str) -> Place:
        return self._places[place_id]

    def __contains__(self, place_id: object) -> bool:
        return place_id in self._places

    def resolve(self, raw: str) -> Place | None:
        """The place for a source's country text; None when the text is empty."""
        text = collapse_ws(raw)
        if not norm_name(text):
            return None
        place_id = self._aliases.get(norm_name(text))
        if place_id is not None:
            return self._places[place_id]
        part_of = _PART_OF.match(text)
        if part_of:
            parent = self.resolve(part_of["parent"])
            if parent is not None and parent.registered:
                return Place(f"x:{slug(part_of['name'])}", text, None, parent.place_id, False)
        return Place(f"x:{slug(text)}", text, None, None, False)

    def resolve_subdivision(self, parent_id: str, name: str) -> Place | None:
        """A registered subdivision of ``parent_id`` called ``name`` (UK + Scotland -> GB-SCT)."""
        place_id = self._aliases.get(norm_name(name))
        if place_id is None or self._places[place_id].parent != parent_id:
            return None
        return self._places[place_id]
```

Create `scripts/build_places.py`:

```python
"""Build data/places.yaml (spec §6.2).

Inputs: pycountry (ISO 3166-1 and -2), data/feed_country_history.tsv (frozen
display names) and data/places_manual.yaml. The output is committed and its
diff reviewed; nothing reads pycountry at runtime.

Display name, first rule that applies:
1. the majority spelling in feed history (a tie goes to the legacy canonical);
2. the manual display (subdivisions, extra places) or a display override;
3. the legacy canonical name from v1's COUNTRY_SYNONYMS;
4. pycountry's common_name, else its name.

    .venv\\Scripts\\python.exe -m scripts.build_places
"""

import sys
from pathlib import Path
from typing import Any

import pycountry
import yaml

from elections_calendar.text import norm_name, slug

ROOT = Path(__file__).resolve().parent.parent
HISTORY = ROOT / "data" / "feed_country_history.tsv"
MANUAL = ROOT / "data" / "places_manual.yaml"
OUT = ROOT / "data" / "places.yaml"

# v1 scraper.py COUNTRY_SYNONYMS: canonical name per ISO code, and its other keys.
LEGACY_CANONICAL: dict[str, str] = {
    "US": "United States", "RU": "Russia", "CD": "DR Congo", "KR": "South Korea",
    "KP": "North Korea", "IR": "Iran", "SY": "Syria", "GB": "United Kingdom",
    "TR": "Turkey", "CZ": "Czech Republic", "SK": "Slovakia", "LA": "Laos",
    "VN": "Vietnam", "TW": "Taiwan", "TZ": "Tanzania", "BO": "Bolivia",
    "VE": "Venezuela", "MD": "Moldova", "MK": "North Macedonia", "SZ": "Eswatini",
    "CV": "Cape Verde", "TL": "East Timor", "MM": "Myanmar",
}  # fmt: skip
LEGACY_ALIASES: dict[str, list[str]] = {
    "US": ["usa", "u.s.", "u.s.a."],
    "CD": ["drc"],
    "GB": ["great britain"],
    "LA": ["lao pdr"],
    "SZ": ["swaziland", "kingdom of eswatini"],
    "MK": ["republic of north macedonia"],
    "MM": ["burma"],
}


COUNTRIES = {country.alpha_2: country for country in pycountry.countries}
SUBDIVISION_CODES = frozenset(sub.code for sub in pycountry.subdivisions)


class BuildError(Exception):
    pass


def load_history(path: Path) -> dict[str, int]:
    counts: dict[str, int] = {}
    for line in path.read_text(encoding="utf-8").splitlines():
        if not line or line.startswith("#") or line == "country\tcount":
            continue
        name, n = line.rsplit("\t", 1)
        counts[name] = int(n)
    return counts


def build(manual: dict[str, Any], history: dict[str, int]) -> dict[str, dict[str, Any]]:
    places: dict[str, dict[str, Any]] = {}
    for code, country in COUNTRIES.items():
        names = {country.name, getattr(country, "official_name", None)}
        names.add(getattr(country, "common_name", None))
        aliases = {n for n in names if n}
        aliases.update(manual["extra_aliases"].get(code, []))
        if code in LEGACY_CANONICAL:
            aliases.add(LEGACY_CANONICAL[code])
            aliases.update(LEGACY_ALIASES.get(code, []))
        places[f"iso:{code}"] = _entry(None, code, None, aliases)
    for code, item in manual["subdivisions"].items():
        if code not in SUBDIVISION_CODES:
            raise BuildError(f"{code} is not an ISO 3166-2 code")
        parent = code.split("-")[0]
        aliases = {item["display"], *item["aliases"]}
        places[f"iso:{code}"] = _entry(item["display"], parent, f"iso:{parent}", aliases)
    for key, item in manual["extra_places"].items():
        if key != slug(item["display"]):
            raise BuildError(f"x:{key} must be x:{slug(item['display'])}")
        aliases = {item["display"], *item["aliases"]}
        places[f"x:{key}"] = _entry(item["display"], None, item["parent"], aliases)
    for place_id, place in places.items():
        if place["parent"] is not None and place["parent"] not in places:
            raise BuildError(f"{place_id} has unknown parent {place['parent']}")
    index = alias_index(places)
    spellings: dict[str, dict[str, int]] = {}
    for raw, n in history.items():
        owner = index.get(norm_name(raw))
        if owner is None:
            raise BuildError(f"history string {raw!r} matches no place; add an alias")
        spellings.setdefault(owner, {})[raw] = n
        places[owner]["aliases"].add(raw)
    for place_id, place in places.items():
        place["display"] = _display(place_id, place, spellings.get(place_id, {}), manual)
        place["aliases"].add(place["display"])
    alias_index(places)
    return places


def _entry(
    display: str | None, code: str | None, parent: str | None, aliases: set[str]
) -> dict[str, Any]:
    return {"display": display, "country_code": code, "parent": parent, "aliases": set(aliases)}


def alias_index(places: dict[str, dict[str, Any]]) -> dict[str, str]:
    """norm_name(alias) -> place_id; two places sharing an alias fail the build."""
    index: dict[str, str] = {}
    for place_id, place in sorted(places.items()):
        for alias in place["aliases"]:
            key = norm_name(alias)
            if not key:
                raise BuildError(f"{place_id} has an empty alias")
            owner = index.setdefault(key, place_id)
            if owner != place_id:
                raise BuildError(f"alias {alias!r} names both {owner} and {place_id}")
    return index


def _display(
    place_id: str, place: dict[str, Any], spellings: dict[str, int], manual: dict[str, Any]
) -> str:
    code = place["country_code"]
    manual_display = place["display"]  # set for subdivisions and extra places
    is_country = place_id.startswith("iso:") and "-" not in place_id
    override = manual["display_overrides"].get(code) if is_country else None
    if spellings:
        top = max(spellings.values())
        leaders = sorted(name for name, n in spellings.items() if n == top)
        if len(leaders) == 1:
            chosen = leaders[0]
        elif LEGACY_CANONICAL.get(code) in leaders:
            chosen = LEGACY_CANONICAL[code]
        else:
            raise BuildError(f"{place_id}: history tie {leaders} and no legacy canonical name")
        if override is not None or manual_display not in (None, chosen):
            raise BuildError(f"{place_id}: a manual display conflicts with feed history")
        return chosen
    if manual_display:
        return str(manual_display)
    if override is not None:
        if code in LEGACY_CANONICAL:
            raise BuildError(f"{place_id}: display override conflicts with the legacy name")
        return str(override)
    if code in LEGACY_CANONICAL:
        return LEGACY_CANONICAL[code]
    country = COUNTRIES.get(code)
    if country is None:
        raise BuildError(f"{place_id}: no display name")
    return str(getattr(country, "common_name", None) or country.name)


def render(places: dict[str, dict[str, Any]]) -> str:
    body = {
        place_id: {
            "display": place["display"],
            "country_code": place["country_code"],
            "parent": place["parent"],
            "aliases": sorted(place["aliases"]),
        }
        for place_id, place in sorted(places.items())
    }
    header = "# Generated by scripts/build_places.py from pycountry, feed history and\n"
    header += "# data/places_manual.yaml. Do not edit; edit the inputs and rebuild.\n"
    return header + yaml.safe_dump(body, allow_unicode=True, sort_keys=False, width=100)


def main() -> int:
    manual = yaml.safe_load(MANUAL.read_text(encoding="utf-8"))
    places = build(manual, load_history(HISTORY))
    OUT.write_text(render(places), encoding="utf-8", newline="\n")
    print(f"{len(places)} places -> {OUT.relative_to(ROOT)}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

Create `elections_calendar/offices.py`:

```python
"""Office classification (spec §6.3) and level evidence (spec §6.4).

``classify`` turns one office text (already split with ``split_offices``)
into an ``Office``. The order of the rules matters:

1. a chamber of the place named by its IPU name or an alias ("State Duma",
   "Knesset"). Names built only from generic words ("Senate", "House of
   Commons") count only nationwide or for a by-election, so "Virginia,
   Senate" is not the US Senate;
2. referendum, head of state, governor, mayor;
3. generic chamber words: "senate" -> the place's one upper chamber,
   "house of representatives" -> its one lower chamber (or its only
   chamber), nationwide or for a by-election;
4. local bodies ("municipal", "local", "city council", ...);
5. generic legislature words ("Parliament", "Legislative", "Congress"):
   identity only for a unicameral place, nationwide or for a by-election;
   otherwise an aggregate (spec §6.3);
6. "General" and anything unrecognised: class ``general``, aggregate.
"""

import re
from collections.abc import Iterable
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import yaml

from elections_calendar.model import JurisdictionKind, Kind, Level, OfficeClass
from elections_calendar.text import collapse_ws, norm_name, slug

DEFAULT_INSTITUTIONS = Path(__file__).resolve().parent.parent / "data" / "institutions.yaml"


def _rx(pattern: str) -> re.Pattern[str]:
    return re.compile(pattern, re.IGNORECASE)


_ROUND = _rx(
    r"\(?\s*\b(?:(?P<n>\d)(?:st|nd|rd|th)|(?P<w>first|second|third|fourth))[\s-]+round\b\s*\)?"
    r"|\(?\s*\bround\s+(?P<k>\d)\b\s*\)?"
    r"|\(?\s*\brun[\s-]?offs?\b\s*\)?"
)
_ROUND_WORDS = {"first": 1, "second": 2, "third": 3, "fourth": 4}
_BY_ELECTION = _rx(
    r"\bby[\s-]?elections?\b|\bspecial elections?\b|\bpartial elections?\b"
    r"|\bsupplementary elections?\b"
)
_REFERENDUM = _rx(
    r"\breferend(?:um|ums|a)\b|\bplebiscites?\b|\bpopular (?:votes?|initiatives?)\b"
    r"|\bballot (?:measures?|questions?)\b"
)
_HEAD_OF_STATE = _rx(r"\bpresiden(?:t|ts|cy|tial)\b")
_GOVERNOR = _rx(r"\bgovern(?:or|ors|orial|atorial)\b|\bgubernatorial\b")
_MAYOR = _rx(r"\bmayor(?:s|al|alty)?\b")
_UPPER = _rx(
    r"\bsenat(?:e|es|orial)\b|\bupper (?:house|chamber)\b"
    r"|\bhouse of (?:lords|elders|councillors|councilors)\b"
)
_LOWER = _rx(
    r"\bhouse of (?:representatives|commons|deputies|delegates|assembly)\b"
    r"|\bchamber of deputies\b|\blower (?:house|chamber)\b|\bhouse of the people\b"
)
_LEGISLATURE = _rx(
    r"\bparliament(?:s|ary)?\b|\blegislat(?:ive|ures?)\b|\bnational assembly\b"
    r"|\bassembl(?:y|ies)\b|\bcongress(?:ional)?\b|\bdiet\b"
)
_LOCAL = _rx(
    r"\b(?:municipal(?:ity|ities)?|local|city|town|village|parish|communal|commune|district"
    r"|county|borough|ward|metropolitan)\b"
)
_REGIONAL = _rx(r"\b(?:regional|region|provincial|prefectural|departmental|cantonal)\b")
_COUNCIL = _rx(r"\bcouncil(?:s|lors?|lers?)?\b")
_GENERAL = _rx(r"\bgeneral\b")
_PLURAL_BODY = _rx(r"\b(?:councils|assemblies|elections|governors|mayors)\b|\band\b")
_GOVERNORS = _rx(r"\bgovernors\b")
_MAYORS = _rx(r"\bmayors\b")
_GENERIC_CHAMBER_WORDS = (_UPPER, _LOWER, _LEGISLATURE)
_HOUSES: tuple[tuple[re.Pattern[str], OfficeClass], ...] = (
    (_UPPER, "upper_house"),
    (_LOWER, "lower_house"),
)


@dataclass(frozen=True, slots=True)
class Chamber:
    name: str
    office_class: OfficeClass  # lower_house | upper_house | legislature (unicameral)
    designation: str  # direct | indirect | appointed | other
    aliases: tuple[str, ...]

    @property
    def names(self) -> tuple[str, ...]:
        return (self.name, *self.aliases)


@dataclass(frozen=True, slots=True)
class Office:
    label: str
    office_class: OfficeClass
    institution: str | None
    aggregate: bool
    kind: Kind
    round: int | None
    level_hint: Level | None
    recognised: bool


class InstitutionRegistry:
    def __init__(self, chambers: dict[str, tuple[Chamber, ...]]) -> None:
        self._chambers = chambers

    @classmethod
    def load(cls, path: Path = DEFAULT_INSTITUTIONS) -> InstitutionRegistry:
        raw: dict[str, list[dict[str, Any]]] = yaml.safe_load(path.read_text(encoding="utf-8"))
        return cls(
            {
                place_id: tuple(
                    Chamber(c["name"], c["office_class"], c["designation"], tuple(c["aliases"]))
                    for c in items
                )
                for place_id, items in raw.items()
            }
        )

    def chambers(self, place_id: str) -> tuple[Chamber, ...]:
        return self._chambers.get(place_id, ())

    def unicameral(self, place_id: str) -> Chamber | None:
        chambers = self.chambers(place_id)
        if len(chambers) == 1 and chambers[0].office_class == "legislature":
            return chambers[0]
        return None


def institution_id(place_id: str, chamber: Chamber) -> str:
    return f"{place_id}/{slug(chamber.name)}"


def extract_round(text: str) -> tuple[int | None, str]:
    """('President (1st round)') -> (1, 'President'). A run-off is round 2."""
    match = _ROUND.search(text)
    if match is None:
        return None, collapse_ws(text)
    if match["n"]:
        number = int(match["n"])
    elif match["w"]:
        number = _ROUND_WORDS[match["w"].casefold()]
    elif match["k"]:
        number = int(match["k"])
    else:
        number = 2
    rest = collapse_ws(f"{text[: match.start()]} {text[match.end() :]}").strip(" ,;-")
    return number, rest


def _contains(haystack: str, needle: str) -> bool:
    key = norm_name(needle)
    return bool(key) and re.search(rf"(?:^| ){re.escape(key)}(?: |$)", haystack) is not None


def _generic(name: str) -> bool:
    return any(p.search(name) for p in _GENERIC_CHAMBER_WORDS)


def _named_chamber(text: str, chambers: Iterable[Chamber]) -> tuple[Chamber, str] | None:
    """The chamber whose longest name or alias occurs in ``text``."""
    key = norm_name(text)
    best: tuple[Chamber, str] | None = None
    for chamber in chambers:
        for name in chamber.names:
            if _contains(key, name) and (best is None or len(name) > len(best[1])):
                best = (chamber, name)
    return best


def _chamber_of_class(chambers: tuple[Chamber, ...], office_class: str) -> Chamber | None:
    matches = [c for c in chambers if c.office_class == office_class]
    return matches[0] if len(matches) == 1 else None


def keyword_class(text: str) -> OfficeClass | None:
    """The office class generic words in ``text`` point to, ignoring the place."""
    if _REFERENDUM.search(text):
        return "referendum"
    if _HEAD_OF_STATE.search(text):
        return "head_of_state"
    if _GOVERNOR.search(text):
        return "governor"
    if _MAYOR.search(text):
        return "mayor"
    if _UPPER.search(text):
        return "upper_house"
    if _LOWER.search(text):
        return "lower_house"
    if _LOCAL.search(text):
        return "local_council"
    if _LEGISLATURE.search(text):
        return "legislature"
    if _REGIONAL.search(text) or _COUNCIL.search(text):
        return "local_council"
    if _GENERAL.search(text):
        return "general"
    return None


def classify(
    label: str,
    place_id: str,
    jurisdiction_kind: JurisdictionKind,
    registry: InstitutionRegistry,
) -> Office:
    """Classify one office text for a place (spec §6.3); see the module docstring."""
    text = collapse_ws(label)
    round_, rest = extract_round(text)
    by_election = _BY_ELECTION.search(rest) is not None
    nationwide = jurisdiction_kind == "nationwide"
    chambers = registry.chambers(place_id)

    def office(
        office_class: OfficeClass,
        *,
        institution: str | None = None,
        aggregate: bool = False,
        level: Level | None = None,
        recognised: bool = True,
        kind: Kind | None = None,
    ) -> Office:
        if kind is None:
            if aggregate:
                kind = "aggregate"
            elif by_election:
                kind = "by_election"
            else:
                kind = "candidate_election"
        return Office(text, office_class, institution, aggregate, kind, round_, level, recognised)

    named = _named_chamber(rest, chambers)
    if named is not None and (not _generic(named[1]) or nationwide or by_election):
        found = named[0]
        return office(
            found.office_class, institution=institution_id(place_id, found), level="national"
        )
    if _REFERENDUM.search(rest):
        level: Level | None = "national" if nationwide else (
            "subnational" if jurisdiction_kind == "named" else None
        )
        return office("referendum", level=level, kind="referendum_day")
    if _HEAD_OF_STATE.search(rest):
        institution = f"{place_id}/president" if nationwide else None
        return office(
            "head_of_state", institution=institution, level="national" if nationwide else None
        )
    if _GOVERNOR.search(rest):
        return office("governor", aggregate=bool(_GOVERNORS.search(rest)), level="subnational")
    if _MAYOR.search(rest):
        return office("mayor", aggregate=bool(_MAYORS.search(rest)), level="subnational")
    for pattern, house in _HOUSES:
        if pattern.search(rest):
            chamber = _chamber_of_class(chambers, house)
            if house == "lower_house" and chamber is None:
                chamber = registry.unicameral(place_id)
            if chamber is not None and (nationwide or by_election):
                return office(
                    chamber.office_class,
                    institution=institution_id(place_id, chamber),
                    level="national",
                )
            return office(house)
    if _LOCAL.search(rest) or (
        _REGIONAL.search(rest) and not _LEGISLATURE.search(rest)
    ) or (_COUNCIL.search(rest) and not _LEGISLATURE.search(rest)):
        single_body = jurisdiction_kind == "named" and not _PLURAL_BODY.search(rest)
        return office("local_council", aggregate=not single_body, level="subnational")
    if _LEGISLATURE.search(rest):
        if _REGIONAL.search(rest):
            return office("legislature", level="subnational")
        only = registry.unicameral(place_id)
        if only is not None and (nationwide or by_election):
            return office(
                "legislature", institution=institution_id(place_id, only), level="national"
            )
        return office("legislature", aggregate=True)
    return office("general", aggregate=True, recognised=bool(_GENERAL.search(rest)))


def split_offices(text: str, place_id: str, registry: InstitutionRegistry) -> list[str]:
    """Split a list of offices ("President (1st round), Chamber of Deputies and Senate").

    Commas first, then "and"/"&", never inside parentheses. A split is kept
    only when every part names an office and the parts are not all of one
    class, so "regional and municipal elections" and "President and Vice
    President" stay whole.
    """
    parts: list[str] = []
    for chunk in _split_if_offices(text, (",",), place_id, registry):
        parts.extend(_split_if_offices(chunk, (" and ", " & "), place_id, registry))
    return parts


def _split_if_offices(
    text: str, separators: tuple[str, ...], place_id: str, registry: InstitutionRegistry
) -> list[str]:
    whole = collapse_ws(text)
    parts = [p for p in (collapse_ws(x) for x in _split_top_level(whole, separators)) if p]
    if len(parts) < 2:
        return [whole] if whole else []
    classes = [_class_of(p, place_id, registry) for p in parts]
    if all(c is not None for c in classes) and len(set(classes)) > 1:
        return parts
    return [whole]


def _class_of(part: str, place_id: str, registry: InstitutionRegistry) -> OfficeClass | None:
    named = _named_chamber(part, registry.chambers(place_id))
    if named is not None:
        return named[0].office_class
    return keyword_class(part)


def _split_top_level(text: str, separators: tuple[str, ...]) -> list[str]:
    parts: list[str] = []
    depth = 0
    start = 0
    i = 0
    lowered = text.casefold()
    while i < len(text):
        char = text[i]
        if char == "(":
            depth += 1
        elif char == ")":
            depth = max(depth - 1, 0)
        elif depth == 0:
            sep = next((s for s in separators if lowered.startswith(s, i)), None)
            if sep is not None:
                parts.append(text[start:i])
                i += len(sep)
                start = i
                continue
        i += 1
    parts.append(text[start:])
    return parts


def resolve_level(default: Level | None, hints: Iterable[Level | None]) -> Level:
    """Spec §6.4: office/institution evidence overrides the source default.

    Conflicting evidence gives ``unknown``; no evidence gives the default,
    or ``unknown`` when the source has none.
    """
    evidence = {h for h in hints if h is not None and h != "unknown"}
    if len(evidence) > 1:
        return "unknown"
    if evidence:
        return evidence.pop()
    return default or "unknown"


_STOP = frozenset({"of", "the", "and", "for", "in", "a", "an", "election", "elections"})


def _stems(label: str) -> set[str]:
    words = [w for w in re.split(r"[\W_]+", label.casefold()) if len(w) > 1 and w not in _STOP]
    return {w[:6] for w in words}


def labels_similar(a: str, b: str) -> bool:
    """v1's 6-character stem overlap (>= 40% of the smaller label's words).

    Used by the merge only to generate candidates within one office class
    (spec §6.3); it never decides identity. Two different stated rounds are
    never similar.
    """
    round_a, rest_a = extract_round(a)
    round_b, rest_b = extract_round(b)
    if round_a is not None and round_b is not None and round_a != round_b:
        return False
    stems_a, stems_b = _stems(rest_a), _stems(rest_b)
    if not stems_a or not stems_b:
        return True
    return len(stems_a & stems_b) / min(len(stems_a), len(stems_b)) >= 0.4
```

```python
def ipu_chambers(html: str, places: PlaceRegistry) -> dict[str, list[dict[str, Any]]]:
    table = BeautifulSoup(html, "lxml").find("table")
    if table is None:
        raise BuildError("no table in the IPU page")
    rows = table.find_all("tr")
    header = [collapse_ws(c.get_text(" ")).casefold() for c in rows[0].find_all(["th", "td"])]
    col = {name: header.index(name) for name in (
        "country", "chamber", "structure of parliament", "chamber type",
        "principal mode of designation of members",
    )}  # fmt: skip
    out: dict[str, list[dict[str, Any]]] = {}
    for row in rows[1:]:
        cells = [collapse_ws(c.get_text(" ")) for c in row.find_all("td")]
        if len(cells) < len(header):
            raise BuildError(f"short IPU row: {cells}")
        if _SUSPENDED.search(cells[col["chamber"]]):
            continue  # a suspended chamber holds no elections
        place = places.resolve(cells[col["country"]])
        if place is None or not place.registered:
            raise BuildError(f"IPU country {cells[col['country']]!r} is not a registered place")
        unicameral = cells[col["structure of parliament"]].casefold() == "unicameral"
        chamber_type = cells[col["chamber type"]].casefold()
        office_class = "legislature" if unicameral else CHAMBER_TYPES.get(chamber_type)
        if office_class is None:
            raise BuildError(f"unknown chamber type {chamber_type!r} for {place.place_id}")
        designation = cells[col["principal mode of designation of members"]].casefold()
        out.setdefault(place.place_id, []).append(
            {
                "name": cells[col["chamber"]],
                "office_class": office_class,
                "designation": DESIGNATIONS.get(designation, "other"),
                "aliases": [],
            }
        )
    return out


def build(html: str, manual: dict[str, Any], places: PlaceRegistry) -> dict[str, Any]:
    chambers = ipu_chambers(html, places)
    for place_id, by_name in manual["aliases"].items():
        for name, aliases in by_name.items():
            match = [c for c in chambers.get(place_id, []) if c["name"] == name]
            if len(match) != 1:
                raise BuildError(f"{place_id} has no IPU chamber called {name!r}")
            match[0]["aliases"] = sorted(aliases)
    for place_id, extra in manual["extra"].items():
        if place_id in chambers:
            raise BuildError(f"{place_id} is already in the IPU table")
        if place_id not in places:
            raise BuildError(f"{place_id} is not a registered place")
        chambers[place_id] = [
            {
                "name": c["name"],
                "office_class": c["office_class"],
                "designation": c["designation"],
                "aliases": sorted(c.get("aliases", [])),
            }
            for c in extra
        ]
    for place_id, items in chambers.items():
        classes = [c["office_class"] for c in items]
        unicameral = classes == ["legislature"]
        bicameral = sorted(classes) == ["lower_house", "upper_house"]
        if not (unicameral or bicameral):
            raise BuildError(f"{place_id}: chambers {classes} are neither uni- nor bicameral")
    return {place_id: chambers[place_id] for place_id in sorted(chambers)}


def render(institutions: dict[str, Any]) -> str:
    header = "# Generated by scripts/build_institutions.py from the IPU chamber table and\n"
    header += "# data/institutions_manual.yaml. Do not edit; edit the inputs and rebuild.\n"
    return header + yaml.safe_dump(institutions, allow_unicode=True, sort_keys=False, width=100)


def main() -> int:
    manual = yaml.safe_load(MANUAL.read_text(encoding="utf-8"))
    html = IPU_TABLE.read_text(encoding="utf-8")
    institutions = build(html, manual, PlaceRegistry.load())
    OUT.write_text(render(institutions), encoding="utf-8", newline="\n")
    print(f"{len(institutions)} places with chambers -> {OUT.relative_to(ROOT)}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```python
"""Throwaway certificates for the local HTTPS test server.

urllib3 2 verifies with VERIFY_X509_STRICT, so these carry the extensions a
real CA and server certificate have: CA basic constraints and key usage,
key identifiers, and a server-auth leaf whose subjectAltName lists its hosts.
"""

from dataclasses import dataclass
from datetime import UTC, datetime, timedelta
from ipaddress import ip_address
from pathlib import Path

from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID

_PEM = serialization.Encoding.PEM


@dataclass(frozen=True)
class Authority:
    key: ec.EllipticCurvePrivateKey
    cert: x509.Certificate

    def write(self, path: Path) -> Path:
        path.write_bytes(self.cert.public_bytes(_PEM))
        return path


@dataclass(frozen=True)
class ServerCert:
    chain: Path  # leaf then CA, as a server sends it
    key: Path


def _name(common_name: str) -> x509.Name:
    return x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, common_name)])


def _usage(*, sign_certs: bool) -> x509.KeyUsage:
    return x509.KeyUsage(
        digital_signature=True,
        content_commitment=False,
        key_encipherment=False,
        data_encipherment=False,
        key_agreement=False,
        key_cert_sign=sign_certs,
        crl_sign=sign_certs,
        encipher_only=False,
        decipher_only=False,
    )


def authority(common_name: str) -> Authority:
    key = ec.generate_private_key(ec.SECP256R1())
    now = datetime.now(UTC)
    cert = (
        x509.CertificateBuilder()
        .subject_name(_name(common_name))
        .issuer_name(_name(common_name))
        .public_key(key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(now - timedelta(days=1))
        .not_valid_after(now + timedelta(days=30))
        .add_extension(x509.BasicConstraints(ca=True, path_length=0), critical=True)
        .add_extension(_usage(sign_certs=True), critical=True)
        .add_extension(x509.SubjectKeyIdentifier.from_public_key(key.public_key()), critical=False)
        .sign(key, hashes.SHA256())
    )
    return Authority(key, cert)


def server_cert(
    ca: Authority,
    directory: Path,
    name: str,
    *,
    hosts: tuple[str, ...] = ("127.0.0.1",),
    expired: bool = False,
) -> ServerCert:
    """Issue a server certificate for ``hosts`` and write its chain and key."""
    key = ec.generate_private_key(ec.SECP256R1())
    now = datetime.now(UTC)
    if expired:
        valid_from, valid_to = now - timedelta(days=30), now - timedelta(days=1)
    else:
        valid_from, valid_to = now - timedelta(days=1), now + timedelta(days=30)
    alt_names: list[x509.GeneralName] = []
    for host in hosts:
        try:
            alt_names.append(x509.IPAddress(ip_address(host)))
        except ValueError:
            alt_names.append(x509.DNSName(host))
    cert = (
        x509.CertificateBuilder()
        .subject_name(_name(hosts[0]))
        .issuer_name(ca.cert.subject)
        .public_key(key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(valid_from)
        .not_valid_after(valid_to)
        .add_extension(x509.SubjectAlternativeName(alt_names), critical=False)
        .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
        .add_extension(_usage(sign_certs=False), critical=True)
        .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
        .add_extension(x509.SubjectKeyIdentifier.from_public_key(key.public_key()), critical=False)
        .add_extension(
            x509.AuthorityKeyIdentifier.from_issuer_public_key(ca.key.public_key()),
            critical=False,
        )
        .sign(ca.key, hashes.SHA256())
    )
    chain = directory / f"{name}.pem"
    chain.write_bytes(cert.public_bytes(_PEM) + ca.cert.public_bytes(_PEM))
    key_path = directory / f"{name}.key"
    key_path.write_bytes(
        key.private_bytes(
            _PEM, serialization.PrivateFormat.PKCS8, serialization.NoEncryption()
        )
    )
    return ServerCert(chain, key_path)
```

```python
"""A local HTTPS server with scripted replies, for fetch tests.

Each path has a list of replies served in order; the last one repeats.
Unknown paths get 404. Every request is logged with its headers.
"""

import ssl
import threading
import time
from collections.abc import Iterator, Mapping
from contextlib import contextmanager
from dataclasses import dataclass, field
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from socket import socket
from typing import Any

from tests.support.tls import ServerCert


@dataclass(frozen=True)
class Reply:
    status: int = 200
    body: bytes = b""
    content_type: str = "text/html; charset=utf-8"
    headers: Mapping[str, str] = field(default_factory=dict)
    delay: float = 0.0  # seconds before the status line
    drip: float = 0.0  # seconds between 10-byte pieces of the body


@dataclass(frozen=True)
class Request:
    path: str
    headers: Mapping[str, str]


class _Server(ThreadingHTTPServer):
    daemon_threads = True

    def __init__(self, context: ssl.SSLContext) -> None:
        super().__init__(("127.0.0.1", 0), _Handler)
        self.context = context
        self.replies: dict[str, list[Reply]] = {}
        self.requests: list[Request] = []
        self._lock = threading.Lock()

    def get_request(self) -> tuple[socket, Any]:
        sock, address = super().get_request()
        # The handshake runs in the handler thread, so a client that rejects
        # the certificate never blocks the accept loop.
        tls = self.context.wrap_socket(sock, server_side=True, do_handshake_on_connect=False)
        return tls, address

    def handle_error(self, request: Any, client_address: Any) -> None:
        pass  # failed handshakes and dropped clients are what the tests provoke

    def next_reply(self, path: str) -> Reply:
        with self._lock:
            queue = self.replies.get(path)
            if not queue:
                return Reply(status=404, body=b"not found")
            return queue.pop(0) if len(queue) > 1 else queue[0]


class _Handler(BaseHTTPRequestHandler):
    protocol_version = "HTTP/1.1"
    server: _Server

    def setup(self) -> None:
        self.request.do_handshake()
        super().setup()

    def do_GET(self) -> None:
        self.server.requests.append(Request(self.path, dict(self.headers.items())))
        reply = self.server.next_reply(self.path)
        time.sleep(reply.delay)
        try:
            self.send_response(reply.status)
            self.send_header("Content-Type", reply.content_type)
            self.send_header("Content-Length", str(len(reply.body)))
            for name, value in reply.headers.items():
                self.send_header(name, value)
            self.end_headers()
            if not reply.drip:
                self.wfile.write(reply.body)
                return
            for start in range(0, len(reply.body), 10):
                self.wfile.write(reply.body[start : start + 10])
                self.wfile.flush()
                time.sleep(reply.drip)
        except OSError:
            self.close_connection = True  # the client gave up, as the test intended

    def log_message(self, format: str, *args: Any) -> None:
        pass


class TestServer:
    __test__ = False  # not a pytest test class

    def __init__(self, server: _Server) -> None:
        self._server = server

    @property
    def requests(self) -> list[Request]:
        return self._server.requests

    def url(self, path: str) -> str:
        return f"https://127.0.0.1:{self._server.server_address[1]}{path}"

    def route(self, path: str, *replies: Reply) -> str:
        """Script the replies for ``path``; returns its URL."""
        self._server.replies[path] = list(replies)
        return self.url(path)


@contextmanager

    thread.start()

    finally:
```

```python
    """An absolute limit on the monotonic clock."""

    expires_at: float
    clock: Callable[[], float] = time.monotonic

    @classmethod
    def after(cls, seconds: float, clock: Callable[[], float] = time.monotonic) -> Deadline:
        return cls(clock() + seconds, clock)

    def remaining(self) -> float:
        return self.expires_at - self.clock()

    def earliest(self, other: Deadline) -> Deadline:
        return self if self.expires_at <= other.expires_at else other


@dataclass(frozen=True, slots=True)
class FetchResult:
    url: str
    final_url: str
    outcome: FetchOutcome
    stage: str
    http_status: int | None
    content_type: str | None
    body: bytes
    elapsed_ms: int
    attempts: int
    error_type: str | None = None
    error: str | None = None
    api_code: str | None = None

    @property
    def ok(self) -> bool:
        return self.outcome == "ok"

    def text(self) -> str:
        """The body decoded with the Content-Type charset (UTF-8 if none or unknown)."""
        charset = "utf-8"
        if self.content_type and "charset=" in self.content_type.casefold():
            declared = self.content_type.casefold().split("charset=", 1)[1]
            charset = declared.split(";")[0].strip()
        try:
            return self.body.decode(charset, errors="replace")
        except LookupError:
            return self.body.decode("utf-8", errors="replace")

    def diagnostics(self) -> dict[str, object]:
        return {
            "outcome": self.outcome,
            "stage": self.stage,
            "http_status": self.http_status,
            "final_url": self.final_url,
            "content_type": self.content_type,
            "bytes": len(self.body),
            "elapsed_ms": self.elapsed_ms,
            "attempts": self.attempts,
            "error_type": self.error_type,
            "error": self.error,
            "api_code": self.api_code,
        }


@dataclass(frozen=True, slots=True)
class _Attempt:
    outcome: FetchOutcome
    stage: str
    final_url: str
    http_status: int | None = None
    content_type: str | None = None
    body: bytes = b""
    error_type: str | None = None
    error: str | None = None
    api_code: str | None = None
    retryable: bool = False
    retry_after: float | None = None


class Fetcher:
    def __init__(
        self,
        *,
        verify: str,
        clock: Callable[[], float] = time.monotonic,
        sleep: Callable[[float], None] = time.sleep,
        wall_clock: Callable[[], datetime] = lambda: datetime.now(UTC),
        attempt_timeout: float = ATTEMPT_TIMEOUT_S,
        max_bytes: int = MAX_BYTES,
    ) -> None:
        if not verify:
            raise ValueError("TLS verification needs a CA bundle path")
        self._verify = verify
        self._clock = clock
        self._sleep = sleep
        self._wall_clock = wall_clock
        self._attempt_timeout = attempt_timeout
        self._max_bytes = max_bytes
        self._session = requests.Session()

    def __enter__(self) -> Self:
        return self

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc: BaseException | None,
        tb: TracebackType | None,
    ) -> None:
        self.close()

    def close(self) -> None:
        self._session.close()

    def get(self, url: str, *, deadline: Deadline, mediawiki: bool = False) -> FetchResult:
        started = self._clock()
        attempt: _Attempt | None = None
        for number in range(1, ATTEMPTS + 1):
            remaining = deadline.remaining()
            if remaining <= 0:
                return self._result(url, started, number - 1, _deadline(url, attempt))
            attempt = self._attempt(url, min(self._attempt_timeout, remaining), mediawiki)
            if attempt.outcome == "ok" or not attempt.retryable or number == ATTEMPTS:
                return self._result(url, started, number, attempt)
            wait = BACKOFF_S[number - 1] if attempt.retry_after is None else attempt.retry_after
            wait = min(wait, RETRY_AFTER_CAP_S)
            if wait >= deadline.remaining():
                return self._result(url, started, number, _deadline(url, attempt))
            self._sleep(wait)
        raise AssertionError("unreachable: the last attempt always returns")

    def _result(self, url: str, started: float, attempts: int, a: _Attempt) -> FetchResult:
        return FetchResult(
            url=redact_url(url),
            final_url=a.final_url,
            outcome=a.outcome,
            stage=a.stage,
            http_status=a.http_status,
            content_type=a.content_type,
            body=a.body,
            elapsed_ms=int((self._clock() - started) * 1000),
            attempts=attempts,
            error_type=a.error_type,
            error=a.error,
            api_code=a.api_code,
        )

    def _attempt(self, url: str, timeout: float, mediawiki: bool) -> _Attempt:
        current = url
        attempt_ends = self._clock() + timeout
        for _hop in range(MAX_REDIRECTS + 1):
            try:
                parts = urlsplit(current)
                if parts.scheme != "https":
                    return _Attempt(
                        "fetch_failed", "redirect", redact_url(current),
                        error=f"refusing a non-https URL: {redact_url(current)}",
                    )  # fmt: skip
                response = self._session.get(
                    current,
                    headers={"User-Agent": user_agent(parts.hostname or "")},
                    timeout=max(attempt_ends - self._clock(), 0.001),
                    allow_redirects=False,
                    stream=True,
                    verify=self._verify,
                )
            except (requests.exceptions.RequestException, ValueError) as exc:
                return _failure(exc, "request", current)
            with response:
                if response.is_redirect:
                    try:
                        current = urljoin(current, response.headers["Location"])
                    except ValueError as exc:
                        return _failure(exc, "redirect", current)
                    continue
                return self._read(response, current, attempt_ends, mediawiki)
        return _Attempt(
            "fetch_failed", "redirect", redact_url(current),
            error=f"more than {MAX_REDIRECTS} redirects",
        )  # fmt: skip

    def _read(
        self, response: requests.Response, url: str, attempt_ends: float, mediawiki: bool
    ) -> _Attempt:
        final_url = redact_url(url)
        status = response.status_code
        content_type = response.headers.get("Content-Type")
        chunks: list[bytes] = []
        size = 0
        try:
            while True:
                if self._clock() >= attempt_ends:
                    return _Attempt(
                        "timeout", "read", final_url, status, content_type,
                        error="attempt time limit reached while reading the body",
                        retryable=True,
                    )  # fmt: skip
                # read1 returns what one socket read brings; read() would wait
                # for a whole chunk and let a dripping server outlast the limit.
                chunk = response.raw.read1(_READ_SIZE, decode_content=True)
                if not chunk:
                    break
                size += len(chunk)
                if size > self._max_bytes:
                    return _Attempt(
                        "fetch_failed", "read", final_url, status, content_type,
                        error=f"response larger than {self._max_bytes} bytes",
                    )  # fmt: skip
                chunks.append(chunk)
        except (requests.exceptions.RequestException, urllib3.exceptions.HTTPError) as exc:
            failed = _failure(exc, "read", url)
            return _Attempt(
                failed.outcome, "read", final_url, status, content_type,
                error_type=failed.error_type, error=failed.error, retryable=failed.retryable,
            )  # fmt: skip
        body = b"".join(chunks)
        if status >= 400:
            retry_after = parse_retry_after(response.headers.get("Retry-After"), self._wall_clock)
            return _Attempt(
                "http_error", "http", final_url, status, content_type, body,
                error=f"HTTP {status}",
                retryable=status in RETRY_STATUSES,
                retry_after=retry_after,
            )  # fmt: skip
        if _is_html(content_type) and _CHALLENGE.search(body[:_READ_SIZE]):
            return _Attempt(
                "challenge_page", "challenge", final_url, status, content_type, body,
                error="challenge or block page instead of content",
            )  # fmt: skip
        if mediawiki:
            return _mediawiki(final_url, status, content_type, body, response, self._wall_clock)
        return _Attempt("ok", "done", final_url, status, content_type, body)


def _deadline(url: str, last: _Attempt | None) -> _Attempt:
    detail = f"; last attempt: {last.outcome} at {last.stage}" if last else ""
    return _Attempt(
        "deadline",
        "deadline",
        last.final_url if last else redact_url(url),
        http_status=last.http_status if last else None,
        error=f"deadline reached{detail}",
    )


def _mediawiki(
    final_url: str,
    status: int,
    content_type: str | None,
    body: bytes,
    response: requests.Response,
    wall_clock: Callable[[], datetime],
) -> _Attempt:
    try:
        data = json.loads(body.decode("utf-8"))
    except (UnicodeDecodeError, ValueError):
        return _Attempt(
            "api_error", "api", final_url, status, content_type, body,
            error="MediaWiki response is not JSON",
        )  # fmt: skip
    error = data.get("error") if isinstance(data, dict) else None
    if error is None:
        return _Attempt("ok", "done", final_url, status, content_type, body)
    code = str(error.get("code", "")) if isinstance(error, dict) else ""
    info = str(error.get("info", "")) if isinstance(error, dict) else str(error)
    return _Attempt(
        "api_error", "api", final_url, status, content_type, body,
        error=redact_text(f"MediaWiki error {code}: {info}"),
        api_code=code or None,
        retryable=code == "maxlag",
        retry_after=parse_retry_after(response.headers.get("Retry-After"), wall_clock),
    )  # fmt: skip


def outcome_for(exc: Exception) -> tuple[FetchOutcome, bool]:
    """The outcome of a failed request and whether it is worth retrying.

    TLS errors and timeouts are checked first: requests raises both as
    subclasses of ConnectionError.
    """
    if isinstance(exc, (requests.exceptions.SSLError, urllib3.exceptions.SSLError)):
        return "tls_error", False
    if isinstance(exc, (requests.exceptions.Timeout, urllib3.exceptions.ReadTimeoutError)):
        return "timeout", True
    if isinstance(exc, (requests.exceptions.ConnectionError, urllib3.exceptions.ProtocolError)):
        return ("dns_error" if _is_dns_failure(exc) else "fetch_failed"), True
    return "fetch_failed", False


def _failure(exc: Exception, stage: str, url: str) -> _Attempt:
    outcome, retryable = outcome_for(exc)
    return _Attempt(
        outcome,
        "tls" if outcome == "tls_error" else stage,
        redact_url(url),
        error_type=type(exc).__name__,
        error=redact_text(str(exc)),
        retryable=retryable,
    )


def _is_dns_failure(exc: BaseException) -> bool:
    """Whether a name-resolution error is anywhere in the exception's chain."""
    seen: set[int] = set()
    stack: list[BaseException] = [exc]
    while stack:
        current = stack.pop()
        if id(current) in seen:
            continue
        seen.add(id(current))
        if isinstance(current, (urllib3.exceptions.NameResolutionError, socket.gaierror)):
            return True
        linked = [current.__cause__, current.__context__, getattr(current, "reason", None)]
        linked.extend(current.args)
        stack.extend(e for e in linked if isinstance(e, BaseException))
    return False


def _is_html(content_type: str | None) -> bool:
    return content_type is None or "html" in content_type.casefold()


def user_agent(host: str) -> str:
    """Wikipedia gets the project's bot User-Agent (no personal email); others a browser's."""
    host = host.casefold()
    if host == "wikipedia.org" or host.endswith(".wikipedia.org"):
        return WIKIPEDIA_UA
    return BROWSER_UA


def parse_retry_after(value: str | None, wall_clock: Callable[[], datetime]) -> float | None:
    """Seconds to wait from a Retry-After header (delta-seconds or HTTP-date).

    None when the header is missing or unreadable; the caller then uses its
    own back-off.
    """
    if not value:
        return None
    text = value.strip()
    if text.isdigit():
        return float(int(text))
    try:
        when = email.utils.parsedate_to_datetime(text)
    except (TypeError, ValueError, IndexError):
        return None
    if when.utcoffset() is None:
        when = when.replace(tzinfo=UTC)  # "-0000" dates are UTC with no zone named
    return max(0.0, (when - wall_clock()).total_seconds())


def redact_url(url: str) -> str:
    """Drop user info and the fragment; replace secret-looking query values."""
    try:
        parts = urlsplit(url)
        host = parts.hostname or ""
        port = f":{parts.port}" if parts.port else ""
    except ValueError:
        return "<unparseable URL>"
    if ":" in host:
        host = f"[{host}]"  # IPv6
    query = _SECRET_PAIR.sub(r"\g<key>REDACTED", f"?{parts.query}")[1:] if parts.query else ""
    return urlunsplit((parts.scheme, host + port, parts.path, query, ""))


def redact_text(text: str, limit: int = 500) -> str:
    """Redact every URL in ``text`` (also bare ``/path?key=value``) and cap its length."""
    text = _URL_IN_TEXT.sub(lambda m: redact_url(m.group()), text)
    return _SECRET_PAIR.sub(r"\g<key>REDACTED", text)[:limit]
```

```python
@dataclass(frozen=True, slots=True)
class TrustBundle:
    path: Path
    sources: tuple[str, ...]


def trust_bundle(dest: Path, environ: Mapping[str, str] = os.environ) -> TrustBundle:
    """Write one CA file: certifi's roots plus the machine's configured bundle.

    certifi alone verifies every source on a plain network (OSCE's emSign
    chain included); that is CI. On a machine whose TLS is intercepted by a
    corporate proxy, the proxy's root is only in the bundle named by
    REQUESTS_CA_BUNDLE / SSL_CERT_FILE / CURL_CA_BUNDLE, and that bundle
    alone lacks roots for the sites the proxy lets through untouched.
    Verification stays on everywhere; nothing is trusted that neither lists.
    """
    paths = [Path(certifi.where()).resolve()]
    sources = ["certifi"]
    for name in ENV_CA_BUNDLES:
        value = environ.get(name)
        if not value:
            continue
        candidate = Path(value).resolve()
        if candidate.is_file() and candidate not in paths:
            paths.append(candidate)
            sources.append(name)
    dest.parent.mkdir(parents=True, exist_ok=True)
    dest.write_bytes(b"\n".join(p.read_bytes() for p in paths))
    return TrustBundle(dest, tuple(sources))
```
