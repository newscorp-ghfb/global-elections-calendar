Chrome Extension · How to Use · Version 2.0.0

Global Elections Calendar

Elections worldwide, month by month, merged from 10 monitoring sources and checked every day. The calendar tells you how sure it is of each date, and what is wrong with the data when something is.

Getting started
1
Click the extension icon
The globe icon in your Chrome toolbar opens the popup. It draws the last data it saved, so it opens at once, and then checks for newer data if the last successful check is 30 minutes old or more. The extension also checks in the background about once an hour.
2
Browse by month
Use the ◀ ▶ arrows at the top to move between months. The data covers five months: the previous month, the current month and the next three. A month shows every election whose dates overlap it, so a voting period that runs across two months is listed in both.
3
Open a card to learn more
A card is one place and one date range. Open it to see each contest it groups, what every source says and the date each source gives. Source links open only on that source's own website; if a link is not on the source's own site, the source's home page opens instead.
Reading a card

Each election is shown as a card like this:

19 APR
Ecuador
Presidential Election (Second Round)
Scheduled
Tentative
Show details

The same election reported by several sources is merged into one card; "Show details" lists the sources. The label under the name says what the data supports, not more. A date that is only a month is shown as that month with "day unconfirmed", never with an invented day.

Date and status labels
Scheduled A date in the future, or a voting period that has not ended.
Scheduled voting period: today (approx.) Today falls inside the voting period, and the sources do not disagree.
October — day unconfirmed Only the month is known. A year-only date reads "date unconfirmed".
Expected between 2 Nov and 31 Jan The sources give an expected period, not a date. It also reads "Expected on …" or "Expected in …".
Held A source confirms that the vote took place.
Past The date has passed. Nothing confirms the vote, but the date was exact.
Past expected period — not confirmed An expected period or month that has ended, with no confirmation.
Postponed Pushed to a later date.
Cancelled Called off entirely.
Disputed Legitimacy or results are contested.
Possibly postponed — sources disagree Some sources say postponed, others do not. "Possibly cancelled — sources disagree" is the same for a cancellation.

Small chips and notes can sit beside a label:

Tentative The date is not final.
Subnational A regional or local election.
Rescheduled from … The date or dates it was moved from.
Sources disagree on date Open the card to see each source's date.
Using source data from … A source could not be read, so its last saved copy was used. After a week the note reads "Unverified since …".
Tabs: Upcoming · Past · All
Upcoming
Elections that are scheduled, expected, day-unconfirmed, postponed or in doubt ("sources disagree").
Past (formerly Results)
Elections that are held, or whose date has passed. Postponed elections, and those the sources disagree on ("Possibly … — sources disagree"), stay under Upcoming after their date; cancelled ones are listed only under All. The tab was renamed because it lists elections, not results.
All
Every election in the month, whatever its label. The counters always match the list shown.
The banner: is the data healthy?

One banner under the title shows the worst problem, with counts of errors, warnings and acknowledged issues. Click it to open the source health panel, which lists every source and the reason for each problem. The footer says when the data was generated and when the extension last checked.

Red "Data is N hours old — the daily update hasn't arrived" (older than 36 hours), "The latest update failed its checks — showing the last good data", or "N source errors" (one source error reads "1 source error").
Amber "This data is newer than this extension — update the extension", "Current health can't be confirmed for this data", "Source health isn't available for this data" (data from an older feed), or "N warnings".
Grey Issues that someone has reviewed and acknowledged for a set time. They still describe the real condition.
Green "All sources OK".
Needs attention & undated

Above the list, a collapsed section reads "N items across the monitored window" with the months it covers. It lists what the sources reported but the calendar could not place on a date, or could not match with certainty, each with its source and link. Filters and tabs never hide these items; only the search box narrows them, and then the title says how many of them match.

Long lists: When items are omitted from the feed, the full attention list is in attention_full.json in the publishing run's generation artifact; retrieving it may require operator access, and the artifact is retained for 14 days after upload.
Filtering
Search and level (funnel icon)
Click the funnel icon next to "Schedule" to open the filter bar. Type part of a country, office, source or label to filter the list live. With data from the current feed, a level menu offers All, National + unclassified and Subnational + unclassified.
Options — pinning countries

Right-click the extension icon and choose Options to open the options page (Pinned countries). You can also reach it from chrome://extensions → Details → Extension options.

1
Pin the places you follow
The page lists the places in the data, with your pinned places first. Click the pin icon on a row to pin or unpin it. Pins save at once; there is no Save button. When at least one place is pinned, the popup shows only those places, with a "Pinned view" banner.
2
A pinned country also shows its places
A pinned country also shows the places that belong to it, for example pinning Georgia also shows Abkhazia and South Ossetia. The row says "Also shows" and names them. Pinning one of those places by itself shows only that place.
3
Pins from version 1
Your pins from version 1.0.2 are carried over once, when the extension updates. A pin whose name matches no place is kept in a separate list on the options page, with a Remove button. Those pins do not filter anything. The old "selected countries" checkboxes are gone.
Other controls
Refresh ↻
Checks for new data now, without waiting for the 30-minute interval. Use it if the banner says the data is old.
Help ?
Opens this page any time, from the top-right corner of the popup. It also opens once, when the extension is first installed.
Data sources

Elections are cross-referenced from ten sources, merged into single records, and checked every day. A source that fails its checks is reported in the banner, not hidden:

ElectionGuide Wikipedia (national calendar) Wikipedia (local calendar) NDI OSCE/ODIHR IPU A-WEB EISA Carter Center EEAS

The popup shows both Wikipedia calendars as "Wikipedia".

Window: the data covers five months, from the month before the current one to three months ahead. Elections outside it are not listed.
Updating from version 1

If you installed from the Chrome Web Store, Chrome updates the extension itself and your pins stay. If you loaded the extension unpacked from a folder:

1
Find the folder
Open chrome://extensions and note the folder the extension was loaded from.
2
Empty the folder
Delete the folder's contents, but keep the folder itself.
3
Extract the new version
Extract the version 2 ZIP into that folder.
4
Reload
Back on chrome://extensions, find the extension. Turn on Developer mode (top right) if it is off. Click Reload on its card.
Warning: Don't remove the extension. Removing it deletes your pins and settings, and loading it again from the same folder would not bring them back.
